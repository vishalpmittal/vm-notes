# Notes — master map

Personal knowledge base of technical notes and curated blog content. This file is the top-level routing map: to place a new note, start here, open the matching category's `README.md`, then the narrowest subfolder that fits. Each `README.md` lists its notes with a one-line scope so you can route without opening the notes themselves.

## Categories

- [ai-ml-ds/](ai-ml-ds/README.md) — AI, ML, and data science. Subfolders: agents, agent-teams-harness-eng, claude, concepts, ethics, inference
- [system-design/](system-design/README.md) — architecture & distributed systems. Subfolders: api, case-studies, database (+ case-studies), observability, security
- [leadership/](leadership/README.md) — engineering management & leadership (summaries). Subfolders: project-management, coaching-cases
- [programming/](programming/README.md) — general programming concepts (OOP, concurrency, design patterns, DSA, testing)
- [infra/](infra/README.md) — DevOps, CI/CD, cloud, containers, deployment, IaC
- [product/](product/README.md) — product management frameworks
- [design/](design/README.md) — product design, UX, design systems (empty inspirations/ subfolder)
- [life-coaching/](life-coaching/README.md) — personal growth and life advice
- [security/](security/README.md) — top-level security (owasp-top-10 only; new security notes go under system-design/security/)
- [courses/](courses/README.md) — course notes, one subfolder per course, each with a glossary.md
- dad-jokes/ — humor (no notes yet)
- images/ — centralized flat image store (`yyyymmdd-hhmm-description.ext`); not a note category

## Root files

- [to-do.md](to-do.md) — cross-cutting backlog of notes to write

## Maintaining these indexes

When you add or create a note, add its one-line entry to that folder's `README.md`. When you add a new folder, create its `README.md` and link it from the parent (and from this map if it's a new top-level category).
